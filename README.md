# 个人主页（静态站点）

本仓库包含一个**可直接打开**的个人主页（纯 HTML/CSS/JS，无依赖）。

## 预览

- **最简单**：直接用浏览器打开 `index.html`
- **本地起服务（推荐）**：

```bash
python3 -m http.server 5173
```

然后访问 `http://localhost:5173`

## 自定义你的信息

打开并编辑：

- **`index.html`**：姓名、头衔、简介、社交链接、邮箱等（搜索替换“你的名字 / you@example.com / yourname”即可）
- **`script.js`**：项目卡片列表在 `PROJECTS` 常量里配置（标题、描述、标签、演示/代码链接）
- **`styles.css`**：配色与布局（支持暗色/亮色；按钮/卡片/网格等）

## 已内置功能

- **暗色/亮色主题**：支持跟随系统、并记住你的选择
- **项目列表渲染**：在 `script.js` 里维护数据即可
- **导航体验**：平滑滚动、滚动时高亮当前 section
- **小交互**：返回顶部、复制邮箱
